antd Breadcrumb

Top-bar module menu Standard pattern: Menu bar
antd Menu (mode="horizontal")

A horizontal row of module/model links across the top of the app, filled from the same resource list as the sider, with license-aware filtering and journey shortcuts folded in — the secondary nav surface next to it, not a replacement for it.

Command center Standard pattern: Command palette
custom, full-screen overlay

A keyboard-summoned overlay (Ctrl/Cmd+G) built as a custom backdrop-blurred panel rather than an antd Modal. Empty, it lays out three columns — Pinned records, Recently viewed, and Modules; typing narrows it to matching records grouped by model, a filtered module grid, and typed-command suggestions (e.g. "create "), navigable by arrow keys.

Progressive disclosure

surfacing detail without leaving context
Cascading detail panes Standard pattern: Miller columns (cascading lists)
custom, react-resizable-panels

A resizable list-panel plus stacked detail panes, each level pushing a new column to the right and keeping every ancestor level visible and scrollable — the pattern the request called "miller columns." State is held in URL search params so a drill-down path is shareable.

Data transfer & step navigation

VeloIQ core + Advanced Development extension
Drop zone for file & CSV upload Standard pattern: Drag-and-drop upload (dropzone)
antd Upload.Dragger

A dashed drop target that accepts a dragged file or falls back to click-to-browse. Used in VeloIQ core for image/file field inputs and CSV import, and again in the Advanced Development extension's Media Manager and Data Import/Export Workbench.

Journey execution stepper Standard pattern: Stepper / wizard progress indicator
antd Steps

A multi-position navigator at the top of a running journey. Each position is one step in the journey's sequence; the bar marks completed, current, and pending steps as execution advances — the antd current index is driven by the runner's step state.

Server-rendered searchable, sortable, filterable widget Standard pattern: Faceted data table (with list & gallery variants)
custom, hand-rolled HTML/JS

A search box, multi-column sort, per-column filter popovers, numeric progress bars, and pagination — generated as static HTML and vanilla JS by the backend rather than as a React component, then embedded into a chat answer or dashboard tile.
